# AI Medical Chatbot 🩺

AI Medical Chatbot is a project that lets users ask health-related questions and get responses through a chat interface. The goal is to make finding basic medical information easier using AI.

## Features

- Chat interface for asking medical questions
- AI-generated responses to user queries
- Simple and easy-to-use interface
- Can be extended with more medical data and AI features

## Tech Stack

- Python
- AI / NLP
- Add the frameworks and libraries used in the project

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/22becse52/Ai-Medical-Chatbot.git
cd Ai-Medical-Chatbot
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the project

Run the main application file according to your project setup. For example:

```bash
python app.py
```

Make sure to use the correct filename and setup instructions for this project.
